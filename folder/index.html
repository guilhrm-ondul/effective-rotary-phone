Sobre Mim

Curso: Ciência da Computação

Área de interesse: Desenvolvimento Web e Mobile

Olá! Sou estudante de Ciência da Computação da UNICAP, atualmente cursando desenvolvimento web e mobile. Esta é a minha mini biografia desenvolvida como projeto prático da disciplina.

Atualmente venho aprofundando meus conhecimentos em arquitetura de sistemas, desenvolvimento front-end e práticas modernas de engenharia de software. Busco constantemente criar aplicações acessíveis e eficientes. Já adquiri conhecimentos sobre programação orientada a objetos, banco de dados, compiladores, testes automatizados e busco cada vez mais ampliar minha rede de conhecimentos aplicáveis.

Além dos estudos acadêmicos, me dedico à criação de projetos pessoais, como por exemplo meu projeto de música que continua sendo feito até hoje, ando desenvolvendo aplicações testes de APIs para ampliar ainda mais meus conhecimentos, assim como também tenho projetos mais focados na minha inserção no mercado de trabalho, atualmente desenvolvo um site para uma clínica de procedimentos estéticos.
